## Repository layout

This repo is organized into three top-level folders:

- `mobile/` — the React Native Expo app (all current code lives here). See `mobile/CLAUDE.md` for commands and architecture.
- `frontend/` — placeholder for a future web frontend. No code yet.
- `backend/` — placeholder for a future backend API. No code yet.

When working inside `mobile/`, `cd mobile` first (or run commands with `npm --prefix mobile`), then follow `mobile/CLAUDE.md`.
